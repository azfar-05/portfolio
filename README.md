# Mohammad Azfar — Portfolio

Personal portfolio website built with Next.js, focused on systems-oriented design, AI-assisted engineering workflows, and developer tooling.

---

## Stack

- Next.js 16
- TypeScript
- TailwindCSS
- Framer Motion
- Lenis
- React

---

## Design Direction

The portfolio is designed around:
- editorial minimalism
- systems-inspired interfaces
- restrained motion
- strong typography hierarchy
- debugging/workflow visual language

The goal was to create something that feels:
- technically sharp
- intentional
- cinematic
- authentic
- minimal without feeling empty

---
